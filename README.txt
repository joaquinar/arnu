# ARNU — landing estática

## Uso
Abrí `index.html` en el navegador o publicá todos los archivos de esta carpeta en GitHub Pages, Netlify o cualquier hosting estático. No requiere Node.js, compilación ni base de datos.

## Contacto
Los botones abren WhatsApp al +54 11 2341-1557.

## Imágenes originales
El ZIP de origen contiene archivos `.asset.json` con referencias a imágenes alojadas en el entorno original, pero no incluye los archivos binarios de esas imágenes. Para que esta versión sea autónoma, se recreó la identidad visual con CSS y se mantuvo el favicon incluido. Si compartís los archivos de imagen originales, puedo integrarlos en `assets/` conservando el diseño y optimizando su peso.

## Cambios aplicados
- Una sola página HTML con CSS propio, sin React ni dependencias de ejecución.
- Formulario eliminado; contacto por WhatsApp en navegación, planes, cierre y botón flotante.
- Contenido condensado para evitar repetir mensajes sobre infraestructura, seguridad y mantenimiento.
- Diseño responsive, metadatos SEO, navegación por secciones y respeto a `prefers-reduced-motion`.
- Se conservaron los precios del código original como referencias anuales; confirmar vigencia antes de publicar.
